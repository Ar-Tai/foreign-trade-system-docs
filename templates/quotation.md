# 报价单模板

用途：向客户提供带版本和有效期的商业报价。状态：草稿，填写和审批后方可发送。

| 字段 | 填写内容 |
| --- | --- |
| 报价编号与版本 | 待填写 |
| 卖方及联系人 | 待填写 |
| 买方及联系人 | 待填写 |
| 币种与有效期 | 待填写 |
| 产品与规格版本 | 待填写 |
| 数量 单位 单价 | 待填写 |
| 折扣和额外费用 | 待填写 |
| 贸易术语 版本 指定地点 | 待填写 |
| 付款条件与交货计划 | 待填写 |
| 包装 质检 售后和例外 | 待填写 |
| 提交人与审批人 | 待填写 |

发送前核对明细总额、汇率口径、未包含费用、客户名称、产品版本及批准状态。报价修订时生成新版本并指明替代关系。
