# 商业发票字段模板

用途：组织已确认交易及实际出运的商业资料。不得用于证明未发生的交易或已收到款项。

| 字段 | 填写内容 |
| --- | --- |
| 发票编号 日期 版本 | 待填写 |
| 卖方 买方 收货方 | 待填写 |
| 订单及出运编号 | 待填写 |
| 商品名称 规格 用途 | 待填写 |
| 数量 单位 单价 币种 | 待填写 |
| 费用项目及总额 | 待填写 |
| 贸易术语 版本 指定地点 | 待填写 |
| 原产地及经核实的归类资料 | 按实际要求填写 |
| 运输信息及关联装箱单 | 待填写 |
| 审核和签发记录 | 待填写 |

是否需要特定声明、签章、格式或补充内容，应按具体目的地和交易要求确认。本模板不是全球统一的税务发票。
