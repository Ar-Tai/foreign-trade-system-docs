# 监控告警与运行手册

## 技术指标

请求错误率与延迟、数据库连接与锁等待、慢查询、存储容量、扫描队列、导出队列、Outbox 积压、回调失败率、任务重试和备份结果。告警阈值在容量基线建立后调整，避免使用未验证阈值制造噪声。

## 业务指标

负可用库存、核销超额、审批与资源版本不一致、单证与出运数量不一致、长时间未分配款、过期资质仍被采购使用，以及已撤销用户仍在访问。业务不变量违反应作为高优先级异常，而不是普通报表差异。

## 处理卡片

| 告警 | 首先检查 | 安全动作 | 恢复条件 |
| --- | --- | --- | --- |
| 库存异常 | 来源流水及并发请求 | 暂停受影响库存桶写入 | 对账及修复获批 |
| 核销差异 | 款项状态 分配和冲销链 | 暂停相关分配 | 余额与来源一致 |
| 回调失败 | 签名配置 时间漂移 来源状态 | 隔离失败事件 | 验证连接后幂等重放 |
| 邮件积压 | 服务限流 错误类型 重试量 | 降速或暂停发送 | 发送窗口与配额恢复 |
| 文件扫描失败 | 类型 扫描服务 容量 | 保持附件隔离 | 扫描成功且授权有效 |
| 备份失败 | 容量 权限 连通性 | 告警并补充备份 | 经恢复验证的可用副本 |

## 可观测性关联

请求 ID 连接 API 日志、审计事件、队列任务和外部请求摘要。业务关联使用租户内资源 ID，避免在日志标签中放客户名称或完整订单描述。告警处理后记录原因、影响、恢复时间和预防措施，不以关闭告警按钮作为结案。
