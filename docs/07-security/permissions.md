## 数据范围

用户本人、所属团队、指定客户、指定供应商、指定仓库及租户全部是不同权限范围。字段级权限还应限制采购价格、利润、联系人信息和账户资料。导出、下载和 API 必须复用相同策略，不能只在界面隐藏。

## 强制职责分离

付款申请与最终复核分离；供应商账户变更与付款放行分离；高风险报价提交与审批分离；盘点差异记录与审批分离。临时授权必须设置范围、到期时间和理由。审核人也不能批准自己创建的特殊例外。

## 审查频率

在入职、调岗、离职和重大组织变更时执行权限审查。周期频率由组织确定；审查输出包含不再需要的权限、异常共享账号和超期临时授权，不能只导出账号列表作为已完成证明。
