# 安全与隐私设计

## 风险清单

| 风险 | 控制设计 | 核查证据 |
| --- | --- | --- |
| 横向越权 | 每个资源动作检查租户及归属 | 修改ID的自动化反向用例 |
| 账户接管 | 多因素验证 会话撤销 异常登录监测 | 策略配置及撤销测试 |
| 收款账户欺诈 | 独立渠道核实 双人复核 版本引用 | 账户变更审批链 |
| 文件投毒 | 限制大小 类型检测 隔离扫描 | 上传拒绝和下载阻断测试 |
| 注入和脚本攻击 | 参数化查询 输出编码 安全模板 | 安全测试及代码审查 |
| SSRF | 外部地址严格白名单 禁止任意后端抓取 | 内网地址及重定向测试 |
| 重放及重复扣减 | 签名时间窗 幂等 唯一约束 | 重复回调与并发测试 |
| 导出泄露 | 字段和范围控制 下载时重鉴权 | 撤销权限后的导出测试 |
| 供应链风险 | 最小依赖 固定版本 来源审核 | 依赖清单和变更评审 |
| 备份暴露 | 加密 独立权限 隔离恢复 | 恢复演练及访问记录 |

## 凭据与配置

密钥只在受控的密钥服务或部署环境注入，生产凭据不进入 Git、工单、示例或日志。不提供默认管理员密码，不把数据库管理端口暴露公网。密钥轮换必须包含失效旧密钥、更新使用方和检测失败连接，而不是仅生成新字符串。

## 附件

上传申请分配随机对象 ID，限制大小、允许类型和上传期限；完成上传后校验实际字节、哈希及类型，再进入扫描。下载通过短期授权并重新检查当前角色和业务归属。安全扫描批准是必要条件，不等于文件业务内容已经真实或合规。

## 日志和隐私

日志以业务 ID、请求 ID 和事件结果为主，避免记录完整身份凭据、客户通信、银行账号和原始文件内容。个人信息和商业秘密分别确定访问、保留、脱敏及删除规则。具体市场的数据出境和保留要求需专业核实，本文不提供统一法律期限。

## 安全验收

使用 [OWASP ASVS](https://asvs.owasp.org/) 作为安全控制清单的参考，并按实际应用选择条目、记录证据和例外。当前文档并未完成 ASVS 评估，也不宣称任何安全认证或认证等级。
