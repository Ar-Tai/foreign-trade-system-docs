# 数据导入与迁移

## 导入次序

组织和权限 → 字典及币种 → 品类 → 产品和SKU → 客户供应商 → 期初库存 → 未结订单 → 未结账款及款项 → 附件及关联资料。不能先导入核销，再补充不存在的账单。

## 两阶段导入

第一阶段只预检：格式、必填、编码、父子关系、单位、金额、重复业务号、归属和附件可访问性。生成逐行错误报告和将创建、修改、忽略的数量。第二阶段由有权限者确认后提交，按批次保存来源和导入版本。重复提交同一批次不重复产生业务流水。

## 期初数据

期初库存不是采购收货，需独立初始化流水及盘点证据。期初应收不是新销售收入，需独立迁移标志。旧系统未结余额要能够和迁移后的余额核对，不能把所有历史单据重新执行一遍。

## 切换与回退

迁移前冻结范围并备份，记录各表数量、金额和文件数量。先在隔离环境试迁移及抽样对账，再执行正式切换。回退前明确是否已有新业务写入；有新写入时不能直接用旧备份覆盖，需导出并设计补偿或重放方案。

## 品类数据继承

[catalog.json](../../data/catalog.json) 是业务分类种子，不是可销售库存。产品示例仅用于检索和需求启发，不能自动建成真实商品、供应商或报关资料。特殊监管、二手和服务类索引需结合实际经营范围选择启用。
