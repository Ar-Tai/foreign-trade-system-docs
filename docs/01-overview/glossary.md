# 术语与口径

| 术语 | 系统含义 | 不应混淆 |
| --- | --- | --- |
| 租户 | 数据与授权隔离边界 | 不必等同单个法律主体 |
| 交易方 | 客户或供应商及其关联联系人 | 登录账号不等于交易方本身 |
| SPU | 可选的产品家族分组 | 不是可直接出库的库存单位 |
| SKU | 具体规格及包装的内部库存识别项 | 不是海关编码 |
| MOQ | 供应商或报价约定的最小起订量 | 不是仓库最低库存 |
| 询盘 | 尚待澄清或评估的需求输入 | 不等于销售订单 |
| 报价 | 带版本 有效期和条款的商业提议 | 不等于发票或已收款 |
| PI | 形式发票类文件 | 不自动证明到账或正式结算 |
| CI | 商业发票类文件 | 不自动等同所在地税务发票 |
| PL | 装箱单 | 不替代真实出库和装箱记录 |
| 贸易术语 | 合同中约定的交付规则及指定地点 | 不独立决定所有付款和权属安排 |
| 预留 | 从可用库存划出的待执行数量 | 不减少实物在手数量 |
| 冻结 | 质量或操作原因不可销售的数量分区 | 与预留保持互斥 |
| 在途 | 已离开某仓但未计入目的仓的数量 | 不在两地重复计为可用 |
| 核销 | 把已确认资金分配给账款 | 不等于删除账款 |
| 冲销 | 新增反向记录抵消错误记账 | 不覆盖原始记录 |
| 贡献利润 | 本设计下的订单收入减归集订单成本 | 不宣称等同法定会计净利润 |
| Outbox | 与业务事务同时写入的待发送事件 | 不保证网络层只发送一次 |
| 幂等 | 重试不重复产生同一业务效果 | 不意味着免做权限检查 |
| RPO | 业务可接受的数据恢复点损失目标 | 不是备份文件保留天数 |
| RTO | 从恢复启动到服务可用的目标时长 | 需要恢复演练验证 |

标准分类参考及术语边界见[资料来源](../11-references/sources.md)。
