# 页面导航与关键交互

## 导航结构

工作台、客户商机、产品资料、销售交易、采购生产、质量库存、物流单证、财务成本、售后门户、报表审计和系统设置。菜单按权限可见，但后端授权不能依赖菜单是否显示。

## 表单和确认

金额显示币种，数量显示单位，时间显示时区，无法计算的利润显示资料不完整而非零。保存草稿不等于提交审批，提交审批不等于确认订单。高风险操作的确认框列出业务号、对象版本、金额或数量和实际后果，不能只显示是否确定。

## 并发和异常

收到版本冲突时，显示最新版本与用户未保存修改，允许人工比较再提交，不自动覆盖。网络超时允许使用相同幂等键重试；界面在状态未知时提示查询处理结果，不能直接标记失败并生成新请求。重复点击按钮需要前端防抖及后端幂等两层处理。

## 列表与导出

支持保存过滤条件、列配置、排序和批量操作预览。大批量操作显示影响数量和逐条结果；部分失败不伪装为全部成功。导出任务列明字段、过滤范围、文件有效期和下载权限，默认不导出敏感列。

## 国际化和可访问性

中英文商品名独立保存；多语言模板允许不同长度，不依赖固定字符宽度。表单有可见标签，错误说明关联具体字段；键盘能够到达主要动作。加载、空数据、无权限、部分失败和服务降级分别呈现，避免空白页面让用户猜测。
