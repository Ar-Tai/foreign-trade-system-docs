# M12 外贸单证与关务资料

统一形式发票、商业发票、装箱单和申报资料版本，确保同一出运使用一致的商品与数量快照。

优先级：P0。角色：单证员、业务员、物流员、专业关务人员。实现状态：设计。

## 业务对象与字段

对象：TradeDocument、DocumentRevision、DocumentFieldMapping、CustomsCase、ClassificationRecord。

关键字段：`document_type、document_no、language、source_snapshot_id、revision、hash、issued_at、classification_basis`。

## 正常流程

选择交易与出运 → 合并快照 → 生成草稿 → 单证核对 → 批准发布 → 对外交付 → 修订归档

## 核心规则

1. 本系统提供资料组织和工作流，不自行判定海关归类、税率、许可证或可否进出口。
2. 客户商品名、产品主数据、申报名称和归类依据分开保存，禁止用内部类目编码自动代替申报编码。
3. 单证更正产生新版本并记录替代关系；对外发送只允许批准版本和已通过扫描的附件。

## 需求及验收

| 需求编号 | 需求 | 验收条件 |
| --- | --- | --- |
| REQ-M12-01 | 快照一致性 | 商业发票与装箱单的出运行、数量、单位和交易主体可自动比对。 |
| REQ-M12-02 | 归类证据 | 每个实际使用的归类记录包含辖区、编码版本、用途材料说明、审核人和依据。 |
| REQ-M12-03 | 单证版本 | 已签发文件不得覆盖，修订后旧版本保留并明确失效或被替代状态。 |
| REQ-M12-04 | 文件访问 | 跨租户下载、过期链接和隔离中的附件全部拒绝，下载记录可审计。 |

## 例外处理

信用证要求和客户格式要求作为独立清单，不保证一套通用模板满足银行审单；目的国要求需逐单核查。

## 指标与核查

单证一次通过率、差错数、补件时长、批准后修订次数。
