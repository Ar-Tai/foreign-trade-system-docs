# M08 采购与生产协同

根据销售需求、库存和交期组织采购或代工，并追踪数量、材料、生产节点与延期风险。

优先级：P0。角色：采购员、跟单员、生产协调员、供应商。实现状态：设计。

## 业务对象与字段

对象：PurchaseOrder、PurchaseOrderLine、ProductionMilestone、SupplierConfirmation、MaterialRequirement。

关键字段：`purchase_no、supplier_id、sales_line_links、quantity、unit_cost、promised_date、milestones、inspection_plan`。

## 正常流程

生成需求 → 采购计划 → 供应商确认 → 下单 → 排产 → 过程检查 → 完工 → 验货和收货

## 核心规则

1. 一笔采购可供应多个销售订单，但分配数量之和不能超过采购数量；不隐藏供需关系。
2. 采购确认前检查供应商资格及批准账户；成本和交期的后续变化产生版本。
3. 延期不是自动修改客户承诺日，应发出风险事件并由销售确认新的交期。

## 需求及验收

| 需求编号 | 需求 | 验收条件 |
| --- | --- | --- |
| REQ-M08-01 | 需求分配 | 采购分配到销售行的数量总和可校验，不允许超分配或跨租户分配。 |
| REQ-M08-02 | 生产节点 | 样品、物料到位、生产、包装及出货节点各有计划、实际时间和证据。 |
| REQ-M08-03 | 变更控制 | 已确认采购改价、改量或改交期保留原版本并重新审批受影响项。 |
| REQ-M08-04 | 部分到货 | 采购允许分批收货，已收、拒收、退货和剩余数量可分别追溯。 |

## 例外处理

供应商无法交付时可改派但须释放原分配；生产报工并不直接增加可售库存。

## 指标与核查

采购交期达成率、缺料次数、在制金额、供应商延期天数。
