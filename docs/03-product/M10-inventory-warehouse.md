# M10 库存仓储与批次管理

基于不可覆盖的库存流水记录入库、预留、出库、调拨和调整，支持多仓及批次追溯。

优先级：P0。角色：仓管员、物流员、质检员、财务。实现状态：设计。

## 业务对象与字段

对象：Warehouse、Location、StockLot、InventoryBalance、Reservation、StockMovement。

关键字段：`warehouse_id、sku_id、lot_id、on_hand、reserved、blocked、unit、movement_type、source_document_id`。

## 正常流程

收货待检 → 放行上架 → 销售预留 → 拣货复核 → 出库 → 运输 → 签收或退货

## 核心规则

1. 可用量等于在手减预留减冻结；预留与冻结为互斥数量分区，不得重复扣除同一单位货物。
2. 出库需要原子校验并同时减少在手和对应预留；不允许只改汇总数量而不写流水。
3. 跨仓调拨分为调出在途和调入收货，不能同时计入两个仓库可售库存。

## 需求及验收

| 需求编号 | 需求 | 验收条件 |
| --- | --- | --- |
| REQ-M10-01 | 并发预留 | 可用 10 件时两个各 8 件预留请求至多一个成功，失败请求不留下半条预留。 |
| REQ-M10-02 | 负库存防护 | 出库、冻结、盘亏及预留必须保持各分区非负且预留加冻结不超过在手。 |
| REQ-M10-03 | 流水幂等 | 同一业务来源和操作键重复处理不产生第二笔库存变化。 |
| REQ-M10-04 | 盘点调整 | 盘点差异先冻结范围并审批，再以调整流水入账，保留盘前盘后数量和原因。 |

## 例外处理

临期、破损、待检单独分区；拆箱换单位必须采用明确的换算关系与舍入限制。

## 指标与核查

库存准确率、可用库存、库存周转、库龄、缺货次数。
