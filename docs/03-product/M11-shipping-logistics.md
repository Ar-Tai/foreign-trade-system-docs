# M11 出运物流与交付

把订舱、装箱、分批出运、运输节点和签收异常与订单行关联，避免只记录一个物流单号。

优先级：P0。角色：物流员、跟单员、仓管员、货代。实现状态：设计。

## 业务对象与字段

对象：Shipment、ShipmentLine、Package、Booking、TransportLeg、TrackingEvent。

关键字段：`shipment_no、order_line_id、quantity、packages、gross_weight、net_weight、volume、carrier、tracking_reference`。

## 正常流程

出运计划 → 订舱 → 配货装箱 → 放行复核 → 出库 → 交承运人 → 在途 → 签收 → 异常结案

## 核心规则

1. 一订单可多出运，一出运可含多订单但必须同租户且满足合并条件；用出运行关联而非复制订单。
2. 实际出运数量不得超过有效预留和未交数量；发运前需要库存、质检、收款和单证放行。
3. 外部物流节点是事实事件，不自动等同于收入确认、客户验收或银行收款。

## 需求及验收

| 需求编号 | 需求 | 验收条件 |
| --- | --- | --- |
| REQ-M11-01 | 部分出运 | 1000 件订单可分 400 与 600 件出运，汇总不超过订购量且每批可独立追踪。 |
| REQ-M11-02 | 装箱一致性 | 箱数、重量、体积和箱内明细可逐级校验，毛重不得小于净重。 |
| REQ-M11-03 | 发运守卫 | 缺少出运许可、有效预留或放行文件时禁止 dispatch，不产生库存扣减。 |
| REQ-M11-04 | 轨迹去重 | 重复或乱序运输事件可保留但不回退已确认的业务状态，异常事件进入人工处理。 |

## 例外处理

甩柜、改港、改船和转运新增运输段；签收破损创建索赔，不直接把整单标记失败。

## 指标与核查

准时出运率、在途时长、签收异常率、物流成本。
