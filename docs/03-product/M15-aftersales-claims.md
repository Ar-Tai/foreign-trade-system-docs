# M15 售后退货与索赔

把短装、破损、质量争议和退款与原订单、出运及批次关联，形成证据和费用承担闭环。

优先级：P1。角色：客服、业务员、质检、财务、供应商。实现状态：设计。

## 业务对象与字段

对象：Claim、ReturnAuthorization、ReturnReceipt、CreditAdjustment、ReplacementOrder。

关键字段：`claim_type、order_id、shipment_id、lot_id、claimed_qty、evidence、resolution、responsible_party`。

## 正常流程

客户反馈 → 资格和证据审查 → 责任分析 → 处置审批 → 退货补发或退款 → 复核关闭

## 核心规则

1. 索赔额度与数量受已交付及历史处理数量约束；同一损失不能在多个案件重复赔付。
2. 退货收到前不增加可售库存；收到后先隔离并检验，合格后才转可用。
3. 补发是独立关联订单，退款需要财务流程，业务人员不能单方面标记资金已退。

## 需求及验收

| 需求编号 | 需求 | 验收条件 |
| --- | --- | --- |
| REQ-M15-01 | 索赔关联 | 缺少原订单、出运或有效证据时不能直接批准赔付，特殊例外需说明。 |
| REQ-M15-02 | 数量守恒 | 同一订单行累计退货和补偿处理受规则约束，超量提交被阻断。 |
| REQ-M15-03 | 退货质检 | 退货入隔离区后，未通过检验不得被其他订单预留。 |
| REQ-M15-04 | 关闭条件 | 物流、库存、客户确认及财务调整各自完成后才可关闭，不因客服回复而结案。 |

## 例外处理

客户不退货的退款与实际退货分开；供应商追偿不改变对客户已经批准的赔付事实。

## 指标与核查

索赔率、平均解决时间、重复缺陷、售后损失。
