# M09 质检验货与不合格处理

在来料、生产过程、出货和退货节点记录检验结果，并防止不合格批次流入可售库存。

优先级：P0。角色：质检员、质量主管、采购员、供应商。实现状态：设计。

## 业务对象与字段

对象：Inspection、InspectionItem、Defect、QualityHold、CorrectiveAction。

关键字段：`batch_id、spec_revision、sampling_plan_ref、sample_size、defects、result、reviewer_id、evidence`。

## 正常流程

制定检验计划 → 选取样本 → 检查记录 → 出具结果 → 放行或隔离 → 返工复检 → 关闭问题

## 核心规则

1. 抽样方案和合格判定必须来自已确认计划，不在系统中硬编码一套通用合格阈值。
2. 检验执行人和结果复核人按风险分离；照片只能证明现场记录，不能替代数值和方法。
3. 复检新增记录，不覆盖首次不合格；待检和不合格数量不得参与可用量计算。

## 需求及验收

| 需求编号 | 需求 | 验收条件 |
| --- | --- | --- |
| REQ-M09-01 | 检验依据 | 每次检验引用明确规格版本和检验计划，缺失关键判定项不能提交结果。 |
| REQ-M09-02 | 库存冻结 | 批次被质量冻结后不可新预留或出运，已预留数量进入阻断清单。 |
| REQ-M09-03 | 不合格闭环 | 返工、让步接收、退供应商或报废均需审批及处置数量，处置总量与不合格量相符。 |
| REQ-M09-04 | 证据版本 | 检验报告修订保留原件、哈希、复核人和理由，禁止直接替换已批准报告。 |

## 例外处理

客户指定第三方验货仍要记录关联报告和有效范围；让步接收不能默认替代客户同意。

## 指标与核查

一次合格率、缺陷分类、返工周期、质量损失金额。
