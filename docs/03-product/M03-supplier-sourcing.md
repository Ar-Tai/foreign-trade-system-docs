# M03 供应商与寻源管理

管理供应商能力、询价、样品、资质和绩效，防止采购仅依据最低报价而忽略产能与质量条件。

优先级：P0。角色：采购员、采购主管、质量人员、财务复核员。实现状态：设计。

## 业务对象与字段

对象：Supplier、SupplierContact、SupplierQualification、SupplierOffer、BankAccountRevision。

关键字段：`supplier_code、legal_name、country、capabilities、lead_time_days、moq、currency、qualification_expiry、risk_status`。

## 正常流程

登记供应商 → 资料审核 → 发出询价 → 比价与样品 → 合格供应商评审 → 持续绩效评估

## 核心规则

1. 供应商收款账户变更走独立复核，不接受仅凭邮件或聊天截图直接覆盖付款资料。
2. 报价比较必须统一单位、币种、含税口径、贸易条件、起订量与交期；没有可比条件时不能生成最低价排名。
3. 资质附件和评估结论分开存储，过期、暂停和黑名单状态要影响后续新采购。

## 需求及验收

| 需求编号 | 需求 | 验收条件 |
| --- | --- | --- |
| REQ-M03-01 | 供应商准入 | 未完成必需资料审核的供应商不可被选入正式采购订单。 |
| REQ-M03-02 | 规范化比价 | 同一询价中币种、单位或供货范围不一致时显示差异，不以原始数字直接排序。 |
| REQ-M03-03 | 收款账户变更 | 变更后旧付款申请不自动改账户，新申请需要引用已审批的新账户版本。 |
| REQ-M03-04 | 绩效追踪 | 按订单计算准时交付、合格率及争议次数，可追溯至对应检验与收货记录。 |

## 例外处理

临时供应商例外有期限和授权人；供应商合并先处理关联订单，不能只合并名称。

## 指标与核查

合格供应商数、准时交付率、缺陷率、采购集中度。
