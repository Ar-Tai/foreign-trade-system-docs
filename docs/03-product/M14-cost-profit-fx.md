# M14 成本利润与汇率管理

区分报价测算、订单预计利润和实际结案利润，保留每次汇率与成本来源，避免报表随主数据变化。

优先级：P0。角色：财务、销售主管、经营负责人。实现状态：设计。

## 业务对象与字段

对象：ExchangeRateSnapshot、CostEntry、CostAllocation、ProfitSnapshot、BudgetVersion。

关键字段：`base_currency、quote_currency、rate、rate_at、source、cost_type、allocation_basis、reporting_currency`。

## 正常流程

选择报告币种 → 收集成本 → 确认汇率方向 → 分摊 → 计算预计利润 → 实际对账 → 生成结案快照

## 核心规则

1. 汇率定义固定为 1 base_currency 对应 rate 个 quote_currency，禁止依靠界面顺序猜测方向。
2. 不同币种金额不能直接相加；报告换算记录汇率时间与舍入差额，不宣称为税务或会计核算结论。
3. 收入、采购、物流、质检、包装、平台费用和资金费用分别列示，避免把已含运费再次计入。

## 需求及验收

| 需求编号 | 需求 | 验收条件 |
| --- | --- | --- |
| REQ-M14-01 | 汇率方向 | 示例 1 USD 等于 7.2 CNY 时 50400 CNY 换成 7000 USD，反向计算用倒数且保留精度。 |
| REQ-M14-02 | 分摊守恒 | 按金额、重量或数量分摊的子项合计等于原费用，尾差有明确承接规则。 |
| REQ-M14-03 | 利润重算 | 演示订单收入 12800 USD、合计成本 7600 USD，示例订单贡献利润为 5200 USD。 |
| REQ-M14-04 | 历史冻结 | 修改今日汇率或供应商报价不会重写已关闭订单的成本与利润快照。 |

## 例外处理

尚未收到费用账单时标记暂估；成本缺失不能展示为零成本高利润；报表须显示完整性状态。

## 指标与核查

预计与实际差异、贡献利润率、成本完整率、汇率敞口。
