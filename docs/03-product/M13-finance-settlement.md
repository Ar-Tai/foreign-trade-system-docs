# M13 应收应付与资金核销

按币种管理账单、收款、付款及分摊，支持定金尾款、部分核销、手续费和退款。

优先级：P0。角色：财务录入员、财务复核员、业务主管。实现状态：设计。

## 业务对象与字段

对象：Receivable、Payable、Payment、PaymentAllocation、BankReconciliation、Refund。

关键字段：`currency、gross_amount、bank_net_amount、fee_amount、value_date、counterparty、allocation_amount、reversal_of`。

## 正常流程

形成账款 → 记录到款或付款申请 → 独立复核 → 分配核销 → 对账 → 处理差额 → 结清

## 核心规则

1. 账款与银行流水是不同对象；一笔款可核销多个账单，一张账单可被多笔款核销。
2. 核销不得超出未分配金额和账单未结余额；跨币种核销必须明确换汇交易及差额，不静默换算。
3. 已入账记录通过冲销及新记录纠正，不直接覆盖历史金额；退款与负数收入不是同一个业务。

## 需求及验收

| 需求编号 | 需求 | 验收条件 |
| --- | --- | --- |
| REQ-M13-01 | 定金尾款 | 12800 USD 订单可用 3840 与 8960 两笔款结清，重复导入流水不重复计款。 |
| REQ-M13-02 | 核销上限 | 并发核销同一余额时只接受不超额的提交，失败操作不部分更新账单。 |
| REQ-M13-03 | 手续费分离 | 银行净入账与手续费分别保存，原始收款总额可解释且与核销口径一致。 |
| REQ-M13-04 | 冲销退款 | 冲销保持原始流水可追溯；退款需审批并与原付款及相关信用调整关联。 |

## 例外处理

多收款作为未分配余额而非自动增加订单收入；坏账和汇兑差额使用单独审批与科目映射。

## 指标与核查

应收账龄、未分配款、逾期率、对账差异、付款审批时长。
