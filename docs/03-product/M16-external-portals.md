# M16 客户与供应商门户

向外部交易方开放受限报价确认、订单进度、资料交换和生产回报，不暴露内部成本与其他客户信息。

优先级：P1。角色：客户联系人、供应商联系人、内部授权人。实现状态：设计。

## 业务对象与字段

对象：PortalIdentity、PartyAccessGrant、PortalAction、SharedDocument。

关键字段：`party_id、contact_id、allowed_resources、expires_at、verification_state、external_action_id`。

## 正常流程

内部邀请 → 绑定交易方 → 验证身份 → 查看授权业务 → 提交确认或反馈 → 审核入账 → 撤销权限

## 核心规则

1. 门户身份同时绑定租户和交易方；同域名邮箱不自动继承整家公司订单权限。
2. 外部提交是待核验业务输入，不直接改变库存、财务或审批结果。
3. 共享链接有范围、期限和撤销机制，文件下载前再次检查当前授权。

## 需求及验收

| 需求编号 | 需求 | 验收条件 |
| --- | --- | --- |
| REQ-M16-01 | 交易方隔离 | 客户甲不能通过修改订单编号查看客户乙订单或附件。 |
| REQ-M16-02 | 敏感字段隐藏 | 门户响应和导出均不包含内部成本、利润、其他供应商报价或未授权联系人。 |
| REQ-M16-03 | 确认留痕 | 报价接受记录具体版本、身份验证信息、时间和证据，不仅记录一个勾选状态。 |
| REQ-M16-04 | 撤销即时生效 | 撤销交易方权限后共享链接和已排队的导出下载均不可继续访问。 |

## 例外处理

联系人离职后重新邀请，不共享账号密码；邮件链接不可作为永久认证凭据。

## 指标与核查

门户使用率、外部确认时长、资料往返次数、授权过期数。
