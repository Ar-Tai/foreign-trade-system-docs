# M06 报价与样品管理

形成有版本、有效期和批准范围的报价，并追踪样品费用、快递和客户确认。

优先级：P0。角色：业务员、报价审批人、采购员、样品管理员。实现状态：设计。

## 业务对象与字段

对象：Quotation、QuotationLine、PriceSnapshot、SampleOrder、SampleFeedback。

关键字段：`quotation_no、revision、currency、unit_price、discount、charges、incoterm、named_place、valid_until、sample_status`。

## 正常流程

核算成本 → 编制报价 → 审批 → 发送 → 客户接受或失效 → 样品验证 → 转销售订单

## 核心规则

1. 报价金额用定点十进制计算；按币种精度和固定舍入规则保存明细与总额。
2. 贸易术语同时记录版本及指定地点；付款条件、所有权和验收条件另列，不能从术语名称自动推出。
3. 报价发送后不可原地改价；修订产生新版本，已接受版本不能再次改写。

## 需求及验收

| 需求编号 | 需求 | 验收条件 |
| --- | --- | --- |
| REQ-M06-01 | 报价审批 | 低于授权毛利或超折扣阈值时必须由具备权限且不是提交者的人员审批。 |
| REQ-M06-02 | 报价失效 | 过有效期或被新版本撤回的报价不能接受，服务器按统一时间判定。 |
| REQ-M06-03 | 金额快照 | 数量乘单价、折扣、费用和总额可重算且一致，汇率来源和时间被保留。 |
| REQ-M06-04 | 样品确认 | 记录样品型号、规格版本、费用承担、寄送编号及客户结论，样品通过不替代批量验货。 |

## 例外处理

运费暂估应明确暂估及调整条件；样品免费也要登记内部成本和领用去向。

## 指标与核查

报价响应时间、报价接受率、修订次数、样品通过率。
