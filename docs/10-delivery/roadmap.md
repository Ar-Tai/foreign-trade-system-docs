# 分阶段实施与交付

不在缺少团队规模和技术基础时承诺固定开发周期。下面按交付条件划分阶段，阶段完成需要实际证据。

| 阶段 | 主要范围 | 出口条件 |
| --- | --- | --- |
| D0 需求确认 | 市场 品类 组织 现有系统 关键规则 | 待决策事项确定 需求基线获批 |
| D1 基础主数据 | 身份 权限 品类 SKU 客户 供应商 | 租户隔离及导入测试通过 |
| D2 销售交易 | 询盘 报价 样品 合同 订单 | 一条可复现交易链及版本控制通过 |
| D3 采购履约 | 采购 生产 质检 库存 出运 单证 | 部分交付和异常补偿通过 |
| D4 财务经营 | 应收应付 核销 费用 汇率 报表 | 资金数量对账及并发测试通过 |
| D5 协作集成 | 门户 售后 外部接口 消息 | 外部身份及回调安全测试通过 |
| D6 上线 | 迁移 压测 安全 恢复 UAT | 验收签署及回退演练完成 |

## 切片原则

每个迭代从用户动作到数据、接口、权限、审计和测试形成一个完整切片。例如先实现单币种现货的询盘到回款，再扩展定制生产、多仓和多币种。不能只做界面列表而把状态和金额规则留到最后。

## 交付物

应用源码、数据库迁移、接口与变更记录、自动化测试、运行镜像、部署配置模板、操作手册、恢复记录和已执行验收证据。当前只提供其中的设计文档和文档工具，不包含前述可运行应用交付物。
